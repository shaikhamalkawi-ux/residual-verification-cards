# Licensing

This repository uses a mixed licensing model.

## Author-created code

Author-created source code is licensed under the **BSD 3-Clause License**. See `licenses/BSD-3-Clause.txt`.

## Author-created non-code scientific artifacts

Author-created tables, derived arrays, figures, documentation, schemas, and other non-code scientific artifacts are licensed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. See `licenses/CC-BY-4.0.txt`.

## Third-party materials

Third-party materials retain their upstream licenses and attribution requirements. Publicly hosted external datasets/checkpoints are generally referenced by provenance records rather than redistributed in this public repository.

## Historical review notices

A small number of locked baseline/extension payloads contain `LICENSE_REVIEW.txt` files recording their earlier confidential peer-review packaging state. Those notices are retained only to preserve the locked scientific package and its internal hash verification. For this public release, the BSD-3-Clause and CC BY 4.0 notices above govern the authors' own materials. Nothing here relicenses third-party content.
