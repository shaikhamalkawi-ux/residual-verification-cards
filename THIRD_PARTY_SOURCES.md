# Third-party source policy

RVC uses publicly documented external scientific resources for bounded tests and positive controls. The public GitHub release does not treat those resources as author-owned material.

Where an external dataset, checkpoint, repository snapshot, or issue record is needed, the repository retains source/provenance records, identifiers, URLs, and hashes when available. Large or externally licensed binaries are not re-hosted merely for convenience.

Primary source/provenance records are located within:

- `baseline/01_Calculation_Lock/Source_Provenance/`
- `positive_external_controls/05_CANDIDATE_AND_PROVENANCE/`
- `positive_external_controls/06_PREREGISTRATION/`
- `external_challenge/06_FRESH_SOURCE_POOL/`
- `external_challenge/07_FRESH_HELDOUT_CASES/`
- `interoperability/01_Public_Record_Ledger/`

Third-party materials retain their original licenses and citation requirements.
