# Residual181 public-release notes

Public repository package prepared from the locked Residual181 submission artifacts.

## Preserved

- Baseline RVC scientific payload and verifier.
- Cross-object extension scientific payload and verifier.
- Public-facing external-challenge code/configuration/provenance/results.
- Public-facing positive-control code/configuration/provenance/results.
- Public source ledger, acquisition tools, and interoperability metadata.
- Revised supplementary material.

## Intentionally omitted from the public repository

- Main manuscript and highlighted manuscript.
- Cover letter, response-to-reviewers file, and editorial correspondence.
- Reviewer-response maps.
- Local workstation/path-bearing failed-run logs.
- Third-party checkpoint binaries and source snapshots not required to be re-hosted.
- Source-derived positive-control binary arrays/prediction archives that can instead be reconstructed from the cited upstream artifacts and included code/provenance.

## Scientific claim boundary

The omissions above are public-packaging choices and do not enlarge the manuscript's claim boundary. Residual181 remains bounded conformance evidence, not independent third-party validation, universal external validity, deployment certification, or a residual-to-solution guarantee.
